# .13视觉版作答体验修复（2026-10-26）

当前视觉版源码入口为 prism-next/，后端为 backend/。此分支在此前统一八维源码基础上同步本机 .13 视觉版既有整合与本轮修复；保留旧 frontend/ 供对照，不将旧 Release 宣称为最新视觉版安装包。

本轮修复：可读倒计时与进度条、轮次/任务/发送/状态提示；删除空白等待消息，只保留一个加载提示；修正流式回调读取可变引用导致的重复消息；统一角色第一人称事实陈述并避免重复追加已完整表达的事实；最后一轮在抽取前即发出材料整理状态，前端从最终提交起明确显示计分报告处理。计分中刷新只读查询状态；错误后先重新读取会话，避免重复提交/评分。候选人原话与历史报告不改写。

验证：前后端TypeScript及生产构建通过，120项相关回归通过；包含最后一轮事件顺序、恢复不重复轮次与评分、四情境事实边界及评分/证据契约。独立本地界面服务核验常驻倒计时、单等待提示、流结束消息唯一性、最终轮状态和计分刷新恢复。未新增外部模型调用；本机数据库逐表哈希与修改前一致。浏览器截图及数据库核对仅留本机，不公开作答与日志。

这是源码更新，尚未生成或发布新版视觉版安装包。依赖、模型密钥、后台任务、数据库须在接收方电脑自行配置；127.0.0.1 链接只对本机有效。

追加视觉优化：全站阅读文字设定更明亮的蓝灰色层级，增强按钮与输入边界；情境卡、八维颜色和首页光谱增强饱和度；报告说明字号提升，雷达网格、折线、标签及进度颜色增强对比。保留深色棱镜风格。

视觉层级调整：按UI指导报告恢复A/B/C/E四张核心卡，旧版D移至下方独立次要入口，自定义情境另外列示，均保留原真实路由。核心卡恢复间距和正文留白，窄屏/中屏使用两列，桌面保留散开、聚合与飞牌。标题与重要操作清楚，编号、图标、页脚等辅助信息克制；卡片插画恢复柔和色系，评分图表、作答状态与原话依据保留清晰度。采用独立目录构建后部署，不在运行中的测评目录原位构建。
