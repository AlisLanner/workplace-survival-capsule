# MAAT 应用场景与目标用户

> MAAT · 情境行为评估系统:在高压、多利益相关方情境中,通过多角色对话观察真实行为,输出以用户原话为证据的行为观察报告。

本文档的推导顺序:**先确定适用对象(目标用户与其评估目的),再按适用对象设计情境**——受测者角色层级必须与目标岗位匹配,情境从用途推导,不做用途绑定。

## 1. 适用对象与评估设计

| 适用对象 | 受测者画像 | 角色层级 | 评估目标 | 对应情境 |
|---|---|---|---|---|
| 校招(应届生 → 执行/专业岗) | 无管理经验 | **执行层** | 需求澄清、边界表达、求助担当、抗压稳定 | 入职第一周的需求对接(专为校招设计) |
| 中层选拔(3-8 年 → 管理岗) | 有管理经验或候选管理岗 | 管理岗 | 向上对齐、资源协调、团队管理 | 周三下午的会议室、接手的第三周 |
| 一线运营选拔(服务/运营岗) | 一线管理经验 | 管理岗 | 现场处置、团队协同、危机指挥 | 8号桌的客人、零点大促的故障工单 |
| 管理者培训(现任管理者) | 在职管理者 | 管理岗 | 发展诊断,报告配套建议 | 上述管理岗情境均可 |
| 高校教学(学生) | 任意 | 任意 | 体验与理解,流程教学 | 全部情境,可定制 |

## 2. 情境体系(由适用推导)

### 执行层(校招)

**入职第一周的需求对接**(`first_week_assignment`)
- 受测者:运营组入职第一周的新人——与应届生实际职级一致,角色代入成立。
- 压力结构:主管(许主管)催交付 / 数据组资深(大周)不配合、要交换条件 / 业务方(方姐)质疑新人能力。
- 评估框架(执行层 8 维):需求澄清、优先级判断、横向协作、诚实沟通、边界表达、向上同步、压力表达、担当推进。
- 设计要点:情境里的角色层级刻意低于其他四个情境——新人没有指挥权,只能靠确认口径、守边界、出声升级完成任务,这正是校招要观察的行为。

### 管理岗(中层选拔 / 一线运营选拔 / 管理者培训)

| 情境 | 受测者角色 | 压力结构 | 评估框架 |
|---|---|---|---|
| 周三下午的会议室 | 项目负责人 | 上级(陈总)· 资源方(苏姐)· 新人(小秋) | 任务推进 8 维 |
| 接手的第三周 | 空降项目负责人 | 上级(梁总)· 资深员工(老郑)· 新人(小楠) | 任务推进 8 维 |
| 8号桌的客人 | 值班经理 | 客户(刘总)· 学徒(小林)· 主管(江师傅) | 现场危机 8 维 |
| 零点大促的故障工单 | 值班负责人 | 运营总监(王总)· 客服(小郑)· 研发(老周) | 现场危机 8 维 |

- 中层选拔直接使用任务推进型情境——受测者角色与目标岗位层级一致,生态效度最高。
- 一线运营选拔使用现场危机型情境——角色与目标岗位一致。
- 管理者培训不挑情境(对象本身即情境中的负责人角色),按学员岗位就近选择;报告的发展建议用于面谈。
- 高校教学全部可用,按课程主题选择;离线 mock 模式零成本。

## 3. 三个群体的使用方式

### 3.1 企业人力资源:校招与中层选拔

- 用户:校招项目组、人才发展团队、业务面试官。
- 流程:线上施测(一人一情境)→ 行为观察报告 → 面试官核验证据,辅助面试与评价会议。
- 校招用执行层情境(入职第一周),避免"让应届生扮演负责人"的角色错位;中层选拔用管理岗情境。
- 系统能力:证据可追溯(报告结论回到用户原话)、可靠性门(方差超阈值自动转人工复核,替代评分者一致性管理)、覆盖度门(证据不足自动降级)。
- 缺口:施测批次管理(批量建会话、匿名编号、进度监控、报告导出)、常模与信效度(横向比较需要分场景常模,路线见 MAAT 心理测量学报告)。
- 边界:报告为行为观察参考,选拔结论需人工复核环节;正式使用需知情同意与匿名化。

### 3.2 高校教学:课程教学与课堂实训

- 用户:组织行为学、人才测评、人力资源管理课程教师与学生。
- 能力:离线便携版 + mock 模式零成本;任务卡/开场白/提示词后台可改;对话页阶段条与报告页证据卡可讲解评估方法论。
- 缺口:情境模板库(任务卡变体一键复制改编)、课堂分组账号。

### 3.3 企业内部管理者培训:能力提升诊断

- 用户:培训经理、教练/导师、学员本人。
- 闭环:测评 → 报告(优势/发展关注点/改进建议/下一步建议)→ 教练面谈 → 3-6 个月后复测。
- 缺口:前后测对比视图、报告 PDF 导出、发展建议模板化。

## 4. 三条共性底座

1. **证据可追溯**:全程保留用户原话,报告结论与证据一一对应;Role Agent 看不到评分细则。
2. **可靠性门**:采样方差、覆盖度、mock 来源三重门槛,证据不足自动降级。
3. **双模式运行**:真实 DeepSeek 与本地 mock 一键切换,教学与流程验证零成本。

## 5. 路线图优先级

| 优先级 | 事项 | 服务对象 |
|---|---|---|
| P0 | 施测批次管理(批量建会话、匿名编号、进度监控、报告导出) | 人力资源 |
| P0 | 报告 PDF 导出 | 人力资源、培训 |
| P1 | 前后测对比视图 | 培训 |
| P1 | 情境模板库(任务卡变体一键复制改编) | 高校教学 |
| P2 | 分场景常模与信效度研究(见 MAAT 心理测量学报告) | 人力资源(横向比较) |
| P2 | 课堂分组账号 | 高校教学 |

## 6. 数据与边界

- 报告输出为情境行为观察参考,选拔与晋升结论需人工复核环节;正式使用前完成知情同意与匿名化处理。
- 施测数据用于研究或常模建设时,按研究伦理要求脱敏。
