# MAAT .13 视觉版前端

本目录为接入正式 Express/Prisma 后端的 Next.js 前端，不是旧版静态预览。测评、管理、报告均经同源 `/api` 调用后端；默认前端17927、后端17877。

源码安装：先按仓库后端说明安装依赖、配置本机 backend/.env 并准备数据库。在后端目录运行构建；使用仓库 scripts/local-server.cjs 显式指定本地数据库、端口17877和真实/离线模式。然后在本目录用 pnpm install --frozen-lockfile 安装独立依赖，pnpm build 构建，pnpm start 启动。开发预览使用 pnpm dev。需要其他后端地址时，在构建/开发启动前设置 BACKEND_ORIGIN。

真实模式需要接收方自行配置模型密钥和管理口令；公开仓库不附带数据库、作答记录、日志或本机配置。本机已有安装的17927入口和Windows后台任务独立于此源码分支。此前发布的 .12 Release 安装包没有被这次源码同步替换。

2026-10-26修复：常驻4分钟倒计时、末25秒提示；单个等待提示及流式消息收尾；清楚的轮次与功能标识；最终作答后立即转入计分报告状态；评分中刷新只查询状态，不重复发起收费评分。后端角色事实已改为第一人称口语表达，事实与量规保持原定义，历史消息不改写。

追加视觉优化：全站阅读文字设定更明亮的蓝灰色层级，增强按钮与输入边界；情境卡、八维颜色和首页光谱增强饱和度；报告说明字号提升，雷达网格、折线、标签及进度颜色增强对比。保留深色棱镜风格。
